were folded into module initialisers. Attribution (which package a given module uses) is therefore not
recoverable from `src`. The store, however, is complete: the versions below are exact, because Bun encodes
them in the path. Together they give a rebuild the precise install set; they do not give the mapping from
module to package, and they do not give dependency ranges, peer constraints or scripts.
